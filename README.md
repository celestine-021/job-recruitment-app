# Careerly

Careerly is a responsive job recruitment platform prototype built with React, TypeScript, and Vite. Job seekers can explore and save vacancies, build a profile, and submit applications. Employers can publish listings and review applicants for each role.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, or preview it with `npm run preview`.

## Prototype data

Jobs, saved roles, applications, profiles, and the selected workspace are stored in the browser's local storage. This makes the demo usable without a server or account setup; the data is local to the current browser and is not shared between users or devices.
